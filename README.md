# L++ IDE

Учебная среда разработки для языка **L++** — язык с русским синтаксисом
(`если … то … конец`, `для i от 1 до 10`, `функция`), написанный на Python + Tkinter.
Внутри — свой лексер, парсер, интерпретатор, подсветка синтаксиса, темы,
аддоны и само-тесты.

Версия 2.1 — классы, перебор коллекций, множественный выбор, обработка ошибок,
подключение файлов. Плюс исправленный `run.bat` и 60 автотестов.

---

## Быстрый старт

```bat
run.bat
```

или

```bat
python lpp_ide.py
```

Требуется только Python 3.9+ с Tkinter (входит в стандартную сборку Windows).
Внешних зависимостей нет.

Первый запуск: выбираете издание (Home / Ultimate / Classic), дальше IDE
запоминает выбор в `%APPDATA%\LppIDE\config.json`.

## Что было исправлено (v2.0)

**Критические ошибки ядра**

| Проблема | Было | Стало |
|---|---|---|
| Число в конце файла | `IndexError` на `x = 5` без перевода строки | корректный токен |
| `0xFF` / `1e3` в конце файла | `IndexError` | корректный разбор |
| `//` как оператор | парсер знал `//`, но лексер съедал его как комментарий — деление нацело было недостижимо | `//` и `#` — комментарии, целое деление через `дел(a, b)` |
| Область видимости | новая переменная внутри функции утекала в глобальные | локальные остаются локальными, глобальные по-прежнему изменяемы |
| Глубокая рекурсия | сырой `RecursionError` с трейсбеком Python | понятное сообщение на русском |
| Ошибки типов | `RuntimeError: can only concatenate str (not "int")` | «нельзя применить '+' к строка и число» |

**Ошибки интерфейса**

- **Смена темы стирала код** — окно перестраивалось с нуля и вставляло шаблон.
  Теперь документ, курсор и флаг изменений сохраняются.
- **Диалог `ввести` вызывался из рабочего потока** — Tkinter так нельзя.
  Теперь запрос уходит в главный поток через очередь.
- **Само-тесты писали в консоль из потока** — теперь результат передаётся
  в главный поток.
- **`Сохранить` не сбрасывал флаг изменений** — при выходе всегда спрашивало
  «Сохранить изменения?». Теперь в заголовке честный маркер `•`.
- **GUI-аддоны падали** с `main thread is not in main loop` — добавлен
  автоматический режим запуска в главном потоке для `lgame`, `whooshint`,
  `platidengami`, `nftbar`, `mixday`.
- **Путь к аддонам зависел от текущей папки** — IDE ломалась при запуске из
  ярлыка. Теперь пути считаются от файлов пакета.
- **Подсветка тормозила** — было 29 отдельных поисков по всему тексту на каждое
  нажатие клавиши. Теперь один проход регулярными выражениями.
- **Пасхалка «Build» вешала окно** на `time.sleep` в главном потоке — теперь
  анимация через `after`, ESC пропускает.

**Ошибки аддонов**

- `mixday.СоздатьПлатформер()` вызывал несуществующую `platidengami.СоздатьИгру`
  → `AttributeError`. Исправлено.
- `nftbar` считал координаты от края экрана, а `place()` работает от родителя —
  панель уезжала. Исправлено.
- `webcore.ПроверитьСайт` и `МоеIP` не закрывали соединения и висели без таймаута.
- `helloos.ВыключитьКомпьютер()` выключала ПК без вопросов — теперь спрашивает
  подтверждение (или `LPP_ALLOW_POWER=1`).
- `whooshint`/`platidengami` запускали вложенный `mainloop`, блокируя IDE.

## Что нового в 2.1

**Язык стал заметно полнее:**

| Возможность | Синтаксис |
|---|---|
| Перебор коллекции | `для каждого x из массив то: … конец` |
| Множественный выбор | `выбрать x: вариант 1: … вариант 2, 3: … иначе: … конец` |
| Обработка ошибок | `попробовать: … поймать ошибка: … конец` |
| Классы и объекты | `класс Имя: функция метод(…) … конец конец` + `новый Имя(…)` + `я.поле` |
| Подключение файлов | `включить "модуль.lpp"` |
| Новые функции | `диапазон()`, `соединить()`, `среднее()` |

**Починен запуск:** `run.bat` был записан с LF-переводами строк, а `cmd.exe`
такое не переваривает — получалось `'ythonw' is not recognized`. Теперь файл
в CRLF, с поиском `pythonw`/`python` и понятным сообщением, если Python нет.

**Диагностика:** ошибки запуска больше не исчезают молча (у `pythonw` нет
консоли) — трейсбек пишется в `%APPDATA%\LppIDE\error.log` и показывается
в диалоге.

## Язык L++ — краткий справочник

```lpp
// комментарий (можно и через #)

x = 5
имя = "мир"
флаг = истина
числа = [1, 2, 3]
человек = {"имя": "Аня", "возраст": 17}

если x > 3 то:
    вывести("больше")
иначе если x == 3 то:
    вывести("равно")
иначе:
    вывести("меньше")
конец

пока x > 0 то:
    x = x - 1
конец

для i от 1 до 10 шаг 2 то:
    вывести(i)
конец

функция квадрат(n):
    вернуть n * n
конец

вывести(квадрат(4))
```

**Операторы:** `+ - * / % **`, сравнения `== != < > <= >=`, логика `и или не`.

**Комментарии:** `//` до конца строки и `#` до конца строки.
Целое деление — функция `дел(a, b)`.

**Встроенные функции:** `вывести`, `ввести`, `длина`, `тип`, `число`, `строка`,
`мин`, `макс`, `абс`, `округ`, `случайное`, `модуль`, `дел`, `степень`, `корень`,
`сумма`, `срез`, `диапазон`, `соединить`, `среднее`.

**Перебор коллекции:**

```lpp
для каждого x из [1, 2, 3] то:
    вывести(x)
конец

для каждого буква из "абв" то:   // строки и словари тоже перебираются
    вывести(буква)
конец
```

**Множественный выбор:**

```lpp
выбрать оценка:
    вариант 5:
        вывести("отлично")
    вариант 4:
        вывести("хорошо")
    вариант 1, 2:                 // несколько значений в одном варианте
        вывести("плохо")
    иначе:
        вывести("неизвестно")
конец
```

**Обработка ошибок:**

```lpp
попробовать:
    вывести(10 / 0)
поймать ошибка:                   // имя необязательно
    вывести("сломалось:", ошибка)
конец
```

**Классы:**

```lpp
класс Точка:
    функция создать(x, y):        // конструктор
        я.x = x
        я.y = y
    конец

    функция длина():
        вернуть корень(я.x * я.x + я.y * я.y)
    конец
конец

т = новый Точка(3, 4)
вывести(т.длина())                // 5
т.x = 10                          // поля можно менять
```

**Подключение файлов:**

```lpp
включить "utils.lpp"              // выполнит файл в текущем окружении
```

**Методы строк:** `.верхний()`, `.нижний()`, `.разбить(sep)`, `.заменить(a, b)`,
`.найти(s)`, `.обрезать()`, `.начать_с(s)`, `.кончить_на(s)`, `.длина`.

**Методы массивов:** `.добавить(x)`, `.удалить(x)`, `.вставить(i, x)`,
`.сортировать()`, `.перевернуть()`, `.очистить()`, `.длина`, `.содержит(x)`,
`.индекс(x)`, `.срез(a, b)`, `.копия()`.

**Методы словарей:** `.ключи()`, `.значения()`, `.есть(k)`, `.получить(k, def)`,
`.удалить(k)`, `.очистить()`, `.длина`.

**Области видимости:** блоки `если`/`пока`/`для` не создают новую область;
функция создаёт. Присваивание существующей переменной меняет её там, где она
объявлена, а новая переменная внутри функции остаётся локальной.

## Аддоны

Подключаются строкой `включить имя` — ищутся в `addons/`.

```lpp
включить math
вывести(math.sqrt(16))

включить mixday
вывести(mixday.Сумма(1, 2, 3))
вывести(mixday.ХешMD5("abc"))
```

Встроенные модули: `math`, `random`, `time`, `os`, `sys`, `json`, `re`.
Свои аддоны можно создать в меню **📚 БИБЛИОТЕКИ → Создать** — это обычный
Python-файл, его функции видны из L++.

Аддоны с окнами (`lgame`, `whooshint`, `platidengami`, `nftbar`, `mixday`)
автоматически запускаются в главном потоке — иначе Tkinter падает.

## Тесты

```bat
python -m unittest discover -s tests -t .    :: 60 юнит-тестов

python tests\smoke_ui.py                     :: дымовой тест интерфейса
```

## Известные ограничения

- Язык интерпретируемый, скорость — Python-уровня.
- `включить "файл.lpp"` выполняет файл в текущем окружении (как `#include`);
  отдельных пространств имён у файлов нет.
- Нет наследования классов и приватных полей.
- Один документ за раз (без вкладок).
- Защита от бесконечных циклов: 5 000 000 итераций на цикл.
- Издание Home искусственно ограничивает 200 строк — это часть задумки.
